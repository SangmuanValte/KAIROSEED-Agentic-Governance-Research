## Evidence integrity rules

1. Preserve raw outputs where safe and lawful.
2. Record the source revision used to generate each result.
3. Use a documented digest algorithm and canonicalization procedure.
4. Never overwrite a failed result with a later passing result.
5. Link a corrective test to the original failure.
6. Record missing evidence explicitly.
7. Do not treat a digest as proof of truth, completeness, or authorization.
